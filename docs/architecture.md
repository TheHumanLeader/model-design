# 架构说明

## 目标

`model-design` 是只面向 Vue Vapor 生态的模型设计器，不为 React、原生 JavaScript 或传统 VDOM Vue 单独维护渲染层。

## 分层

### 文档层

`src/types.ts` 定义持久化模型文档。文档不包含选中、拖动、缩放、菜单等临时编辑器状态。

### 核心层

`src/core/` 提供纯 TypeScript 数据构造、导入规范化、几何计算和分组操作。核心层不导入 Vue。

这样做不是为了适配其他框架，而是为了：

- 核心逻辑可单元测试
- 避免组件中混入大量数据规则
- 降低响应式代理范围
- 为后续命令系统、历史事务和 Worker 计算留出边界

### Vapor 组件层

`src/components/` 负责 DOM 渲染、指针交互、配置表单与运行时状态。

所有 SFC 必须使用 Vapor：

```vue
<script setup lang="ts" vapor>
```

禁止在组件主路径使用：

- Options API
- JSX / TSX
- `h()`
- 依赖 VNode 的扩展接口
- 依赖组件实例代理的实现

## 状态归属

### 持久化状态

- 模型
- 字段
- 分组
- 模型与分组归属
- 模型用途
- 字段用途

### 运行时状态

- 当前选中
- 当前悬停
- 拖动手势
- 临时拖动偏移
- 缩放与平移
- 右键菜单
- 撤销重做栈

## 性能路线

当前基线使用 DOM 节点与 CSS `translate3d()`。

后续节点数量扩大后依次加入：

1. 视口矩形计算
2. 不可见模型节点裁剪
3. 连线分层渲染
4. 大规模连线切换 Canvas
5. 空间索引
6. Worker 几何计算

Vapor 负责降低组件更新与运行时开销，但不会替代 DOM 数量控制、布局控制和几何算法优化。
