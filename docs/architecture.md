# 架构说明

## 目标

`model-design` 是只面向 Vue Vapor 生态的模型设计器，不为 React、原生 JavaScript 或传统 VDOM Vue 单独维护渲染层。

## 分层

### 文档层

`src/types.ts` 定义持久化模型文档，包括：

- 模型与模型标签
- 字段与字段属性
- 字段到目标模型、目标字段的关系
- 分组
- 模型与分组归属

文档不包含选中、拖动、缩放、菜单或关系查看焦点等临时编辑器状态。

### 核心层

`src/core/` 提供纯 TypeScript 数据构造、导入规范化、关系完整性清理、几何计算和分组操作。核心层不导入 Vue。

这样做不是为了适配其他框架，而是为了：

- 核心逻辑可单元测试
- 避免组件中混入大量数据规则
- 降低响应式代理范围
- 为后续命令系统、历史事务和 Worker 计算留出边界

### Vapor 组件层

`src/components/` 负责 DOM 渲染、指针交互、配置表单与运行时状态。

所有 SFC 必须使用 Vapor：

```vue
<script setup lang="ts" vapor>
```

禁止在组件主路径使用：

- Options API
- JSX / TSX
- `h()`
- 依赖 VNode 的扩展接口
- 依赖组件实例代理的实现

## 关系模型

每个来源字段最多保存一条关系：

```text
来源模型 / 来源字段
        ↓
关系类型 + 关系名称
        ↓
目标模型 / 可选目标字段
```

关系只存一份，不在目标模型上保存反向副本。关系查看阶段根据全部字段关系实时建立入向与出向索引，避免双向数据不同步。

当前“查看关系模型”只展示一跳直接关系：

- 当前模型保持高亮
- 入向和出向直接关系模型保持可见
- 其他模型与无关分组透明化
- SVG 只绘制当前焦点相关的关系

## 样式归属

组件不管理浅色、深色或自动主题状态。默认视觉只是一组 CSS 变量的初始值；宿主项目通过覆盖 `--md-*` 变量接管外观。

这避免组件内部主题状态与业务项目的主题系统重复或冲突。

## 状态归属

### 持久化状态

- 模型
- 模型标签
- 字段
- 字段关系
- 分组
- 模型与分组归属
- 模型用途
- 字段用途

### 运行时状态

- 当前选中
- 当前悬停
- 拖动手势
- 临时拖动偏移
- 缩放与平移
- 右键菜单
- 当前关系查看焦点
- 撤销重做栈

## 性能路线

当前基线使用 DOM 节点、CSS `translate3d()` 和按需 SVG 关系线。

后续节点数量扩大后依次加入：

1. 视口矩形计算
2. 不可见模型节点裁剪
3. 关系索引缓存
4. 连线分层渲染
5. 大规模连线切换 Canvas
6. 空间索引
7. Worker 几何计算

Vapor 负责降低组件更新与运行时开销，但不会替代 DOM 数量控制、布局控制和几何算法优化。
